# computer-use-win (DSH plugin bundle)

Configuration-only DeepSeek Harness bundle that connects the local `computer-use-win` MCP server over
stdio. It contributes no Host or Client code: a single YAML patch inserts the shipped
`@deepseek-ai/dsh-mcp-client` row with `serverName: computeruse`, so the tools appear as
`mcp__computeruse__*`.

This directory is generated by the release's `install.ps1`:

- `cordis.patch.yml` — rendered from `cordis.patch.yml.template` with absolute paths for node, the
  server entry point, the policy file, and the working directory. Re-run `install.ps1 -Force` instead
  of editing it.
- `package.json` — declares `dsh.bundle.patch`, the localized metadata exports, and the icon.
- `locale/en.json`, `locale/zh.json`, `docs/DETAIL.md`, `icon.svg` — what the Plugins page shows.

Install it once per DSH profile: **Plugins** > **Add plugin**, choose this directory, then start a new
session and call `list_granted_applications` with `include_desktop: true`. Removing the plugin row from the same page unregisters the server;
the release's `uninstall.ps1` refuses to delete the files while a profile still references the bundle.
