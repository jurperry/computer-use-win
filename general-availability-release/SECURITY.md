# 安全模型（安装者视角）

这个服务能真实操作你的桌面，所以它的权限模型值得在安装前读一遍。细节实现见
`payload/computer-use-win/docs/SECURITY.md`。

## 1. 信任边界

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| 人（你） | 编辑 `policy.json`、按 ESC 中止、点 UAC 确认 | —— |
| agent（模型） | 调用 27 个工具 | 改策略文件、给自己授权、绕过拒绝名单 |
| 服务端 | 截图、注入输入、枚举窗口 | 自提权、访问安全桌面、驱动 SYSTEM 进程 |
| 插件包 | 声明"用哪个 node + 哪个 server + 哪个策略" | 执行任何代码（它没有 index.js） |

**唯一的授权来源是策略文件。** 没有"agent 请求 → 弹窗同意"的路径：`request_access` 只报告现状，
不会改文件。这是刻意的——一个会点"删除"的服务不该把授权交给被授权的模型。

## 2. 档位与门禁

| 档位 | 截图/看窗口 | 点击/拖拽/滚轮 | 打字/组合键 | 剪贴板 |
|---|---|---|---|---|
| `none` | ✗ | ✗ | ✗ | ✗ |
| `read` | ✓ | ✗ | ✗ | 读 ✓ / 写 ✗ |
| `click` | ✓ | ✓ | ✗ | 读 ✓ / 写 ✗ |
| `full` | ✓ | ✓ | ✓ | 由 flag 决定 |

- 档位按**目标 exe**（不是窗口标题）判定；`unlisted` 决定未列出的应用。
- `deny` 永远优先；另有内置拒绝名单（`lsass.exe`、`winlogon.exe`、`csrss.exe`、`consent.exe`、
  `logonui.exe`、`services.exe`、`smss.exe`、`wininit.exe`、`securityhealthservice.exe`、`msmpeng.exe`）。
- 输入前校验"鼠标按下时窗口是谁"（鼠标）与"前台是谁"（键盘）；截图后目标窗口移动/改变大小会拒绝
  使用旧坐标，避免点到错误的位置。
- 系统级快捷键（Win 键、Ctrl+Alt+Del 之外的系统组合）由 `systemKeyCombos` 单独控制，默认关闭。
- posted 消息通道（`backgroundInput`）默认关闭：它绕过前台校验，且只对框架分类器判定为经典 USER32 / 未识别类的绑定窗口启用（控件树被截断时按 `unknown` 处理，走真实输入），只在明确需要时打开。

## 3. 人在回路

- **ESC 中止**：低层键盘钩子只认物理按键；服务端自己注入的 ESC（`LLKHF_INJECTED`）不算。正在执行的
  动作会尽快停下，`computer_batch` 在两个动作之间停止，`wait` 立即返回。
- **绑定窗口描边**：`open_application` 后在窗口外侧画一圈绿框，你能看见 agent 正在操作哪个窗口；
  `switch_display` 或清理时自动消失。
- **点击档剪贴板防护**：目标应用处于 `click` 档时，真实剪贴板被暂存并清空，防止它的"粘贴"按钮
  注入你或 agent 之前放进去的内容；退出该状态后恢复。服务端拿不到剪贴板明文（`clipboardRead`
  仍受 flag 控制）。

## 4. 提权

- 默认不提权。只有当目标窗口完整性级别高于服务端、且策略 `elevation: true` 时，才会**通过 UAC
  询问你**；你拒绝就只是返回错误。
- 提权助手是独立进程，命名管道 DACL 只允许当前用户 SID，带 nonce 与父进程校验，主进程退出即自杀。
- UAC 的安全桌面（`consent.exe` / `logonui.exe`）永远不可自动化——这是 Windows 的设计，本服务不去
  绕它。因此"能否操作管理员窗口"取决于你是否愿意点那一次 UAC，而不是 agent 的意愿。

## 5. 它不防什么

- 本机已经在运行的恶意程序、键盘记录器、注入到服务端进程的代码。
- 截图中出现的敏感信息（邮件、密码管理器、聊天窗口）——agent 看得见你屏幕上的一切。
- 锁屏、切换用户、远程桌面断开后的会话：服务端会返回 `feature_unavailable`，而不是继续操作。
- 你自己把 `open` + `systemKeyCombos: true` + 空 `deny` 全打开后的后果。

## 6. 部署建议

- 策略文件放在 `%USERPROFILE%\.computer-use-win`，不要放进任何被同步/共享的目录。
- 与他人共用机器时各自安装（默认路径按用户隔离），不要共享同一个 `control.lock.d`。
- 演示、录屏、给客户看时用 `safe` 预设：连截图都要先列出应用。
- 需要审计时把 `CU_LOG_LEVEL` 设为 `debug`：所有拒绝原因、策略来源、目标解析都写在 stderr 上。
- 不用时在插件页移除，或直接 `uninstall.ps1`；移除后没有任何后台进程残留。
